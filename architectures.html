Core Patterns

Major architectural families.

Conceptual entry points into the architecture space. The searchable registry above remains the canonical data-driven layer.

01 / ATTENTION

Transformer

Attention-centered sequence processing using stacked blocks, residual pathways and feed-forward computation.

02 / SPARSE

Mixture of Experts

Conditional computation routes tokens through selected expert modules instead of activating every expert.

03 / STATE

State-Space Models

Sequence modeling through state representations designed to provide efficient processing of long sequences.

04 / GENERATIVE

Diffusion

Iterative denoising-based generation, especially important for image, video and multimodal generation.

05 / MULTIMODAL

Vision-Language

Visual and language representations connected through encoders, projectors, cross-attention or shared spaces.

06 / EFFICIENT

Efficient Attention

GQA, MQA, sliding/local attention and related mechanisms reduce memory or compute requirements.

07 / HYBRID

Hybrid Sequence Models

Combine multiple sequence-processing mechanisms to balance quality, memory, throughput and context length.

08 / CUSTOM

Specialized Designs

Model-specific blocks and combinations can be represented as dedicated architecture records when evidence supports them.
